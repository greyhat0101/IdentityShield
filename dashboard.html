Security Recommendations
🔑
Change Compromised Passwords
Immediately change passwords for all breached accounts. Use a password manager to create unique 16+ character passwords.
CRITICAL — Do This Now
📱
Enable Multi-Factor Authentication
Add MFA to every account that supports it. This single step blocks 99.9% of automated attacks even if passwords are stolen.
CRITICAL — Do This Now
🔒
Use Unique Passwords
Never reuse passwords. If one account is breached, hackers try the same credentials on other sites — called credential stuffing.
IMPORTANT
📧
Update Recovery Email
Keep your recovery email and phone number updated. This ensures you can regain access if your account is compromised.
IMPORTANT
🔔
Set Up Login Alerts
Enable login notifications so you are alerted immediately if someone signs into your accounts from an unfamiliar device or location.
RECOMMENDED
🌐
Use a VPN on Public Wi-Fi
Public Wi-Fi networks are vulnerable to man-in-the-middle attacks. Always use a VPN when connecting outside your home network.
